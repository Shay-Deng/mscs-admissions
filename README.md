# MSCS Admissions

简体中文 | [English](README.en.md)

面向北美计算机及相关硕士项目的申请指导 Skill，帮助你客观选校、核实项目信息，并梳理适合自己的申请表达。

## 选校定位

结合本科背景、原始 GPA、专业和申请季分析竞争力，以可追溯的录取案例支持判断。区分录取门槛与项目价值，将同一申请者的多校结果放在一起看，避免用保底录取低估背景，或用单个顶尖录取高估机会。

GPA 是评估的核心因素。科研、实习和项目经历结合具体项目的要求判断，不因用户的自信或焦虑改变定位。

## 官网检索与文书思路

检索项目官网、申请要求、培养方向和教师研究领域，结合你的真实经历，提供选材角度、思考问题和表达结构。区分官网明确要求与分析建议，帮助你说明为什么适合这个项目、希望在其中获得什么。

## 使用

本仓库根目录就是技能目录，入口为 [SKILL.md](SKILL.md)。下载或克隆后，将整个目录放入所用工具的技能目录，文件夹命名为 `mscs-admissions`。

```text
mscs-admissions/
├── SKILL.md
├── agents/
├── references/
└── scripts/
```

示例：

> 使用 $mscs-admissions，根据我的本科背景、GPA 和目标申请季，给出有依据的选校定位。

> 使用 $mscs-admissions，检索目标项目的官网，帮我从已有经历中梳理文书思路。

官网检索使用运行环境提供的网页搜索和浏览能力。本地资料检索需要 Python 3.9+；数据更新另需 curl。
